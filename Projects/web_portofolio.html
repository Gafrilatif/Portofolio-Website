3D Portofolio

A showcase of my 3D modeling and animation projects, demonstrating creativity and technical skills.

Key Features

  • Immersive 3D Scene: Built with Three.js to render interactive 3D objects in real-time.
  • Performance First: Zero framework overhead. The application manages the DOM and WebGL render loop directly.
  • Responsive Design: Seamlessly adapts the 3D camera aspect ratio and UI to mobile and desktop screens.
