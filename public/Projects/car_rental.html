Car Rental App

A robust desktop application designed to streamline vehicle rental operations. Built with Python and a Graphical User Interface (GUI), this system replaces manual logging with an interactive dashboard for managing cars, customers, and billing.

Key Features

  • Interactive Dashboard: A visual menu with buttons to navigate between "Rent Car", "Return Car", and "View Inventory".
  • Stock Monitoring: Keep track of available vehicles and their rental status.
  • Automated Billing: Input customer details and rental duration via text fields, the system computes the total price automatically based on hourly/daily rates, displays a generated invoice on the screen.
  • Data Persistence: Updates the inventory file instantly when a car is rented or returned, ensuring data is saved even after closing the app.

Tech Stack

Language: Python 3
GUI Framework: Tkinter
Data Storage: .txt / .csv files (File handling for data persistence)
Architecture: Event-driven programming
