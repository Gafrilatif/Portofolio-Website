## 👋 About Me
Hi, I'm **Gafrilatif A.P.A.**, a Bachelor of Information and Communication Technology (BICT) graduate from Asia e University. 

This repository contains the source code for my personal portfolio website. Unlike typical React or Vue portfolios, I chose to build this using **Native JavaScript (Vanilla JS)** to ensure maximum performance and granular control over the WebGL context.

## 🚀 The Project
This project showcases my skills in frontend development and 3D graphics. It features:
* **Immersive 3D Scene:** Built with [Three.js](https://threejs.org/) to render interactive 3D objects in real-time.
* **Performance First:** Zero framework overhead. The application manages the DOM and WebGL render loop directly.
* **Responsive Design:** Seamlessly adapts the 3D camera aspect ratio and UI to mobile and desktop screens.

## 🛠️ Tech Stack
* **Core:** Native JavaScript (ES6+ Modules)
* **3D Engine:** Three.js
* **Styling:** CSS3
* **Build Tool:** Vite (for module bundling and hot module replacement)

## 💻 Getting Started

To run this project locally on your machine:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Gafrilatif/Portofolio-Website.git](https://github.com/Gafrilatif/Portofolio-Website.git)
    cd Portofolio-Website
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).
